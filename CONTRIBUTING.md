# Contributing

Thanks for contributing! Please open an issue to discuss major changes before submitting a pull request.

## Development setup
- Create the environment: `conda env create -f environment.yml`
- Activate it: `conda activate sport_science_muay_thai`

## Formatting (optional)
- Python: `python -m black .` (if Black is installed)
- R: `Rscript -e 'styler::style_dir("scripts/r")'` (if styler is installed)

## Pull requests
- Keep changes focused and include brief context in the PR description.
- Add or update documentation when behavior or outputs change.
