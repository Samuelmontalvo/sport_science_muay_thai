# Manuscript assets

Use this directory to organize manuscript materials.

- `journal/`: draft manuscript text (e.g., .docx, .tex, .qmd)
- `tables/`: analysis tables exported from scripts
- `references/`: bibliography files and citation exports (e.g., .bib, .ris)
- `figures/`: final figures should be stored under `figures/final/`

Keep outputs traceable by naming files with date or analysis tag (e.g., `table1_demographics_2025-12-20.csv`).
